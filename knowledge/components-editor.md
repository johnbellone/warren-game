# Editor Component (Web Interface)

## Description
The editor component is a web-based user interface built with Bun and Mantine 9 framework that provides the developer experience for creating and editing game assets.

## Key Functions
- Responsive React-based UI using Mantine 9 components
- Live preview controls
- Project configuration tools
- Multiplayer collaboration features

## Technical Details
- Built with Bun and TypeScript
- Uses React component architecture
- Responsive design with Mantine 9 UI library
- Integrated with Tauri for desktop capabilities

## Integration Points
Connects to:
- Client component through Tauri APIs 
- Server component for multiplayer data
- Game component for real-time updates
