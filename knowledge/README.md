# Knowledge Base

This directory contains project knowledge and documentation in Markdown format.

## Purpose

This knowledge base is managed by the OKF memory system and stores verified, durable findings about this project. It includes decisions, constraints, architecture notes, runbooks, and other project-specific information.

## Guidelines

- Only add content that is verified or decision-making material
- Keep content concise and focused on project-relevant topics
- Use `okf_update` to make changes to these files
